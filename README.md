# Jessica Guillot

Web developer in Stockholm, at [Planboo](https://github.com/Planboo). I trained at SIMPLonMARS, Centrale Marseille.

The project to open is [Flag Quiz](https://github.com/GuillotJessica/countries_flags_quizz), a Flutter game for a child. A round ends at five correct flags, and the score is how many tries that took. It runs on an iPad, on Android, and in a browser, in English, Swedish, or French.

## Flag Quiz

- The round rules live in Dart, apart from the screens.
- Tests cover the rules, the saved score, the language buttons, and the layout on an iPad and in a browser.
- GitHub Actions check the formatting, the analyzer, the tests, and the web and Android builds.

[Read how to run it](https://github.com/GuillotJessica/countries_flags_quizz#start)
